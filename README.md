# BlogSphere

A role-based blogging platform developed using PHP and MySQL. Users can register, log in, create blogs, edit posts, delete posts, and comment on blogs. Admins can manage users, posts, and comments through an admin dashboard.

## Features

### User Module
- User Registration
- User Login and Logout
- Create Blog Posts
- Edit Blog Posts
- Delete Blog Posts
- View Blog Posts
- Add Comments
- User Dashboard

### Admin Module
- Admin Login
- Admin Dashboard
- Manage Users
- Delete Users
- Manage Posts
- Delete Posts
- Manage Comments
- Delete Comments

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP
- phpMyAdmin
- Git
- GitHub
